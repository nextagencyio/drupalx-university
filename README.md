# DrupalX University

University sample content for DrupalX decoupled Drupal distribution.

## Overview

This package provides university-focused sample content for the DrupalX decoupled Drupal distribution.

## Features

* Sample university content
* Example academic pages and layouts
* Demo university site structure
* Reference implementation

## Requirements

* Drupal 10+
* PHP 8.1+

## Installation

Follow the standard Drupal installation procedure using this installation profile.
